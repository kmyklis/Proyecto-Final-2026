# Banco de preguntas para la defensa

## Problema y solución

- ¿Qué evidencia demuestra que el problema existe?
- ¿Quiénes son los usuarios afectados?
- ¿Qué parte del problema no resuelve la aplicación?
- ¿Por qué eligieron esta solución?

## Objetivos y alcance

- ¿Cómo verifican que cumplieron el objetivo?
- ¿Qué función eliminaron para controlar el alcance?
- ¿Qué requisito consideran más importante?

## Base de datos

- ¿Por qué crearon esta tabla?
- ¿Qué relación existe entre estas entidades?
- ¿Qué restricción evita datos incorrectos?
- ¿Cómo restauran la base de datos?

## Desarrollo

- ¿Qué parte desarrolló usted?
- Explique el flujo desde el formulario hasta la base de datos.
- ¿Qué error fue difícil de corregir?
- ¿Qué función depende de otra?

## Pruebas

- Muestre un caso con datos inválidos.
- ¿Qué prueba falló inicialmente?
- ¿Cómo comprobaron la persistencia?

## Git y trabajo colaborativo

- Muestre un issue y su pull request relacionado.
- ¿Cómo resolvieron un conflicto?
- ¿Cómo se distribuyó el trabajo?

## Inteligencia artificial

- ¿Para qué utilizaron IA?
- ¿Qué respuesta tuvieron que corregir?
- ¿Cómo verificaron el código generado?

## Reflexión

- ¿Qué mejorarían con un mes adicional?
- ¿Qué decisión técnica cambiarían?
- ¿Qué aprendieron del trabajo con una organización real?
