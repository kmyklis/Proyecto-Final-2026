# Checklist de revisión del repositorio de equipo

## Organización

- [x] README actualizado.
- [x] Integrantes y roles.
- [x] Issues con responsables.
- [x] Pull requests revisados.
- [x] Rama principal estable.

## Documentación

- [ ] Problema y evidencia.
- [ ] Objetivos y alcance.
- [ ] Requisitos.
- [ ] Carta Gantt.
- [ ] Riesgos.
- [ ] Registro de pruebas.
- [ ] Manual.
- [ ] Uso de IA.

## Base de datos

- [ ] Modelo conceptual.
- [ ] Modelo lógico.
- [ ] Script de creación.
- [ ] Datos de demostración.
- [ ] Sin datos personales reales.

## Producto

- [ ] Aplicación inicia localmente.
- [ ] CRUD principal.
- [ ] Segunda función.
- [ ] Validaciones.
- [ ] Manejo de errores.
- [ ] Datos persistentes.

## Cierre

- [ ] Presentación.
- [ ] PDF.
- [ ] Video de respaldo.
- [ ] Proyecto comprimido.
- [ ] Versión final identificada.
